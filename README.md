# Frequency GTS

This repository records the standing **full-sweep** assurance rule for GTS.

**Mandatory:** A request for a **full sweep** means execution through the DDC/Frequency assurance path **including adversarial tests**, positive and negative controls, safety-gate mutation tests where applicable, regression verification, independent observation and evidence closure. A test-only review is not a full sweep. Missing, blocked, failed or unverified mandatory gates prohibit reporting completion.

See [FULL-SWEEP-CONTRACT.md](FULL-SWEEP-CONTRACT.md) for the exact gate and reporting requirements. This policy document does not itself implement or enforce a runtime gate.
